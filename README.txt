The Malt Shop — Website
=======================

Files
- index.html : the complete site (styles, illustrations and scripts are all inside this one file)

To view: double-click index.html to open it in any web browser.

To put it online: upload index.html to any static host (Netlify, GitHub Pages,
Cloudflare Pages, or your web host's public_html folder).

Before launch, update:
- Facebook link (currently https://facebook.com) -> search "facebook.com" in index.html
- Add real photos if desired
- Prices, if you want them shown on the menu
